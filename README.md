# RTO Locations India

A lightweight dataset and documentation repository for Indian Regional Transport Office (RTO) locations and code mappings.

This repository contains information related to RTO codes, locations, and state/district-level mapping used for vehicle registration and transport-related lookup workflows.

## Contents

- `RTO mapping.xlsx` — Excel sheet containing the RTO location/code mapping data.
- `GitHub Documentation_RTO Locations.docx` — supporting documentation describing the dataset and its structure.

## Purpose

This project is intended to provide a simple, reusable reference for:

- finding RTO codes by location
- mapping transport office data across Indian states and regions
- supporting application development, data analysis, or regional lookup tools

## Notes

The data is organized for easy use in local projects and can be extended as needed for additional states, districts, or application integrations.
